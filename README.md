# Smart Milling Machine

Media Pembelajaran S1 Pendidikan Teknik Mesin untuk mempelajari komponen mesin frais GUT, simulasi troubleshooting berbasis hotspot 360°, dan evaluasi otomatis.

## Fitur

- Modul pembelajaran K3 dan Modul 1–5
- Gambar modul yang dapat diperbesar
- Simulasi rotasi mesin 360°
- Sembilan hotspot troubleshooting
- Lima skenario diagnosis berbasis PBL
- Evaluasi 10 soal dengan skor otomatis
- Responsif untuk laptop dan ponsel

## Menjalankan secara lokal

Buka `index.html` menggunakan browser modern.
